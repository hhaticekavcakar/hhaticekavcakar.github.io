# Hatice Kavçakar – Portfolio

Personal portfolio website of Hatice Kavçakar, Industrial Engineering student at Yaşar University.

**Live site:** https://hhaticekavcakar.github.io/

Built with plain HTML, CSS and JavaScript and published with GitHub Pages.
No frameworks, no build step and no external libraries.

## Folder structure

```
/
├── index.html                 page content
├── style.css                  design (lavender theme, responsive layout)
├── script.js                  menu, project details, optional media
├── README.md
├── assets/
│   ├── images/
│   │   ├── profile.jpg        profile photo
│   │   └── favicon.svg        browser tab icon
│   └── videos/                optional project videos (MP4)
└── documents/
    └── CV.pdf                 CV
```

## Updating the site

Edit or upload files in this repository and commit the changes.
GitHub Pages republishes automatically within a few minutes (refresh with Ctrl+F5).
